# Avance del taller: Clientes y Vehículos

Solo se incluyen Form1 (principal MDI), FrmClientes y FrmVehiculos.
ucCliente y ucVehiculo son controles de captura incluidos dentro de esas dos ventanas.
Vehículos permite elegir Automóvil, Motocicleta o Camioneta en la misma pantalla.

1. Registra un cliente con Guardar; después pulsa Mostrar para ver la lista.
2. Abre Vehículos, selecciona el propietario, captura los datos y guarda.
3. Pulsa Mostrar; selecciona una fila para modificarla o darla de baja.
4. Escribe el ID y pulsa Buscar para consultar un registro.

Los datos permanecen en memoria durante la ejecución. La base de datos sigue pendiente.
Los modelos siguen siendo únicamente Cliente y Vehiculo.
ESTILO_DEL_AVANCE.md identifica los ejemplos consultados y las adaptaciones del taller.
